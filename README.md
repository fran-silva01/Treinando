# Análise de Vendas e Desempenho Comercial com Python

Projeto desenvolvido como prática de **Análise de Dados com Python**, utilizando Pandas e Matplotlib para explorar dados de vendas e identificar padrões de desempenho.

## Objetivo

Analisar os dados de vendas para responder perguntas de negócio e gerar insights sobre o desempenho de lojas, regiões, categorias e vendedores.

## Análises realizadas

* Loja com maior faturamento total;
* Comparação de vendas entre as categorias **Moda** e **Casa**;
* Vendedor com maior faturamento;
* Comparação do faturamento entre regiões;
* Faturamento médio por loja em cada região, considerando a diferença na quantidade de lojas;
* Visualização dos resultados por meio de gráficos.

## Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Principais aprendizados

O projeto permitiu praticar operações de agrupamento (`groupby`), agregação (`sum`), filtros, ordenação, criação de novas variáveis e visualização de dados, além de desenvolver um olhar analítico para transformar dados de vendas em informações relevantes para o negócio.
